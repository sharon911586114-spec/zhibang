③ 报名录入路径（三种方式）

路径 A · 招聘端报名

发布岗位/海报 → 工人扫码报名 → 数据推送 → 审批 → 驻厂接人 → 更新状态

路径 B · 现场录入

驻厂接到工人 → 项目二维码 → 基础信息/OCR录入 → 带入客户、岗位、驻场 → 已接到

路径 C · 渠道名单报备

模板名单或身份证照片 → 中台录入 → 推送驻厂端 → 驻厂确认接人
